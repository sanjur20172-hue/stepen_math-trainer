📘 Свойства степеней

1. Определение степени:

aⁿ = a · a · ... · a (n раз)

2. Умножение степеней (одинаковые основания):

aⁿ · aᵐ = aⁿ⁺ᵐ

Пример: 2³ · 2⁴ = 2⁷ = 128

3. Деление степеней (одинаковые основания):

aⁿ : aᵐ = aⁿ⁻ᵐ (a ≠ 0)

Пример: 5⁶ : 5² = 5⁴ = 625

4. Возведение степени в степень:

(aⁿ)ᵐ = aⁿ·ᵐ

Пример: (3²)⁴ = 3⁸ = 6561

5. Степень произведения:

(a · b)ⁿ = aⁿ · bⁿ

Пример: (2 · 3)² = 2² · 3² = 4 · 9 = 36

6. Степень частного:

(a / b)ⁿ = aⁿ / bⁿ (b ≠ 0)

7. Нулевая степень:

a⁰ = 1 (a ≠ 0)

8. Отрицательная степень:

a⁻ⁿ = 1 / aⁿ (a ≠ 0)

Пример: 2⁻³ = 1/8 = 0,125

9. Первая степень:

a¹ = a
